# [ARDUINO]Buzzer Frequency

## About
Control a buzzers frequency!

## How to Run

Download the Arduino IDE, then copy and paste the code in the file "Tone_Buzzer.ino" into the IDE.

### Building

### Parts Needed

- any Arduino board
- any breadboard
- an active buzzer
- a potentiometer
- 7 wires
